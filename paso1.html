Configuración de Google Sheets

Sincronización automática mediante Apps Script

Ingresa la URL del Webhook para que los resultados de cada usuario se registren automáticamente en columnas separadas de tu hoja de Google Sheets.

¿Cómo configurar Google Sheets en 2 minutos?

  1. Crea una hoja de cálculo nueva en **Google Sheets**.
  2. En el menú ve a **Extensiones → Apps Script**.
  3. Reemplaza el código existente con el siguiente fragmento:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.fecha,
    data.nombre,
    data.empresa,
    data.cargo,
    data.nivelPESV,
    data.arquetipoPESV,
    data.estiloClasico,
    data.puntuacionDetalle
  ]);
  return ContentService.createTextOutput("OK");
}

4. Haz clic en **Implementar → Nueva implementación → Aplicación web**. En *'Quién tiene acceso'*, elige **Cualquier persona** (Anyone). Copia la URL que te genera y págala arriba.
